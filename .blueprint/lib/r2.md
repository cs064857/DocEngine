# lib/r2

## 職責契約

Cloudflare R2（S3 相容）的**唯一 I/O 邊界**：物件讀寫、前綴列表、任務狀態 JSON 的序列化存取，並支援前端覆寫憑證。

- **做**：延遲初始化預設 S3Client；`R2Overrides` 優先於 env；`putObject`/`getObject`/`listObjects`；`tasks/{taskId}.json` 的 `putTaskStatus`/`getTaskStatus`（缺 key → `null`）。
- **不做**：業務狀態機、爬取/清理/skill 邏輯、HTTP 路由、路徑命名策略（交 `helpers.buildR2Key`）、憑證 UI。

## 接口摘要

| 符號 | 輸入 → 輸出 / 副作用 |
|------|----------------------|
| `JobTask` | 任務狀態形狀：`taskId/status/total/completed/failed/failedUrls/retryingUrls?/urls?/date/createdAt?/updatedAt?/domains?/domainSummary?/engineSettings?` |
| `R2Overrides` | 可選 `accountId/accessKeyId/secretAccessKey/bucketName` 覆寫 |
| `putObject(key, content, contentType?, r2?)` | 寫入 R2；預設 `text/markdown`；副作用：PutObject |
| `getObject(key, r2?)` | → UTF-8 字串；空/缺 → throw |
| `listObjects(prefix?, limit=50, r2?)` | → `Contents[]`（可空陣列） |
| `putTaskStatus(taskId, statusObj, r2?)` | key=`tasks/{taskId}.json`，JSON pretty-print，`application/json` |
| `getTaskStatus(taskId, r2?)` | → `JobTask \| null`；僅 `NoSuchKey` 吞掉回 null，其餘 rethrow |

解析規則：有憑證覆寫 → 新建 Client；僅 bucket 覆寫 → 預設 Client + 覆寫 bucket；env 不全且無覆寫 → throw 引導前端/環境變數。

## 依賴拓撲

```
config.r2 ──→ resolveR2 / getDefaultClient
@aws-sdk/client-s3 ──→ Put/Get/ListObjectsV2
task-metadata.StoredTaskEngineSettings ──→ JobTask.engineSettings 型別

API/services（跨 bundle）──→ putObject / getObject / listObjects / putTaskStatus / getTaskStatus
```

同 bundle：`helpers.buildR2Key` 產出 key 後由本模組寫入；`download` 不直接呼叫本模組，而是經 `/api/files`。本檔為全站 R2 寫入/讀取的匯聚點。
